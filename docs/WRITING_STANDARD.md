# 文章生成规范 / WRITING_STANDARD

`CONTENT_GUIDE.md` 规定了文件怎么放、frontmatter怎么填——那是"容器"规范。
本文档规定容器里装的东西：一篇论文式笔记本身该怎么写、图怎么配、视频怎么嵌。
不管是你自己写，还是让agent代写初稿，都按这份来，否则四层结构会写成风格不一的四篇杂文。

---

## 一、文章的固定结构（论文式，非博客式）

每篇笔记必须包含以下部分，顺序固定：

1. **论点（Thesis）**——放在frontmatter的`abstract`里，不在正文重复。一句话说清楚
   "这篇文章要证明/说明什么"，不是"这篇文章要介绍什么"。区别：
   - ❌ "本文介绍近红外光谱在塑料分选中的应用"（介绍性，没有论点）
   - ✅ "近红外能分辨塑料，是因为特定官能团的振动频率落在该波段，这也决定了它分不清哪些材质"（论点，有因果、有边界）

2. **背景与约束（Context & Constraints）**——这层技术面对的物理/工程/成本约束是什么，
   为什么"理想方案"做不到，只能在约束下选择。这是"为什么"叙事的起点，不能跳过直接讲结论。

3. **核心论证（主体，可分2–4个小节）**——每个小节对应一个具体的技术判断点，
   结构是"现象 → 背后的原理 → 这个原理决定了什么取舍"。禁止只罗列现象不给原理。

4. **图示锚点**——凡是涉及空间关系、流程、光谱曲线、对比数据的论证，必须配图，
   不能只用文字描述"如下图所示"却没有图支撑判断。

5. **结论与开放问题**——总结论点是否成立，并诚实列出这个判断的边界条件或还未验证的部分。
   不写"总之，AI分选前景广阔"这类无信息量的收尾。

---

## 二、写作风格准则

- **结构精确 > 宏大框架**：不用"赋能"、"生态"、"范式"这类空词，用具体的因果链条和数据。
- **每个论点必须可反驳**：写完自查——如果有人不同意，他会从哪个环节反驳？如果论点已经强到没人能反驳，说明它可能是套话而不是判断。
- **诚实标注不确定性**：没有实测数据支撑的判断，写"目前观察到…，但未经过大样本验证"，
  不要把猜测包装成结论。
- **禁止的收尾句式**：「随着技术的发展」「未来可期」「前景广阔」——这类句子删掉不影响信息量，说明它本来就不该写。

---

## 三、图片规范

| 项 | 规则 |
|---|---|
| 编号 | `fig-01.png`、`fig-02.png`，按正文出现顺序编号，不跳号 |
| 配图时机 | 只在图能承载文字难以说清的信息时用（曲线、流程、空间关系），不用配图凑版面 |
| 图注 | 必须写清楚"这张图在支撑哪个判断"，不是单纯描述图里有什么。例：❌"图1：分选流程图" ✅"图1：决策层输出到执行层动作之间的坐标转换发生在虚线框内，这是延迟的主要来源" |
| 数据图 | 涉及光谱曲线/性能对比的图，必须标注单位和数据来源（实测/仿真/文献），不能只放图不说数据从哪来 |

---

## 四、视频规范

视频只在以下两种情况使用，其余情况不插视频：

1. **动态过程类**：机械动作、分选流程、实时检测——文字和静态图无法表达"时序"信息时。
2. **对比演示类**：同一物料在不同方案下的效果对比。

视频在正文中的位置固定为**紧跟在它要支撑的论证段落之后**，不放在文章开头（开头是论点，
不是演示）。每处视频前必须有一句文字说明"接下来这段视频要看什么"，例：
"下面这段视频展示了融合前后误分类率的差异，重点看第8秒的边缘料片。"——不能只放一个`<Video />`不给引导。

托管平台：优先B站（免费、国内加载快），embed链接写入`video.url`，具体格式见`CONTENT_GUIDE.md`。

## 五、层级标注（Layer）的判定标准

frontmatter里的`layer`字段不是随便选一个贴近的，判定依据是——**这篇文章的核心论点发生在哪一层的决策边界上**：

| 层级 | 判定问题 |
|---|---|
| 感知层 | 论点是否关于"传感器/信号本身能不能测到、测得准不准" |
| 决策层 | 论点是否关于"从信号到分类判断"这一步的模型/算法取舍 |
| 执行层 | 论点是否关于"判断变成物理动作"过程中的精度/延迟取舍 |
| 运营层 | 论点是否关于"系统级、产线级"的数据流/反馈回路问题 |

一篇文章原则上只归一层——如果发现论点横跨两层，说明这篇该拆成两篇。

## 六、发布前自查清单（写作层面，区别于`publish-check.js`的格式校验）

- [ ] abstract是论点而不是介绍
- [ ] 背景约束部分交代了"为什么不能用理想方案"
- [ ] 每个小节都有"现象→原理→取舍"的完整链条，没有只摆现象
- [ ] 至少一处判断标注了不确定性或边界条件
- [ ] 没有出现「赋能」「生态」「范式」「前景广阔」等空词
- [ ] 每张图都有图注说明支撑哪个判断
- [ ] 视频前有引导句，且视频出现在对应论证之后而非开头
- [ ] layer字段对应文章唯一的核心论点层级
